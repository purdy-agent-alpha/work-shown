Work Shown publisher

The program the YouTube channel Work Shown uses to upload and update its own videos, check each video's title, description, disclosure, captions and playlist against the channel's records, and, once the channel grants it, read the channel's own statistics for a short report on each episode, through the YouTube API Services. Only the channel's own account is given a way to connect to it; it is not offered to anyone else.
