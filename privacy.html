Work Shown publisher Privacy Policy

Effective 20 November 2026.

Work Shown publisher ("the tool") is the program that the YouTube channel Work Shown ("we") uses to update its own videos and to check each video's title, description, disclosure, captions and playlist against the channel's records. It uses the YouTube API Services. It is not offered to anyone else: it runs only on our computer, and only Work Shown's own account gives it access, signed in on our own devices. Google has not verified the app, which limits it to 100 accounts once it is in production. By using the tool, its user, the channel, agrees to be bound by the YouTube Terms of Service. What Google does with data is set out in the Google Privacy Policy.

1. What the tool accesses

Only what the channel's account grants on Google's consent screen, a single permission: "See, edit, and permanently delete your YouTube videos, ratings, comments and captions" (youtube.force-ssl). With it the tool updates the titles, descriptions and the altered or synthetic content disclosure of the channel's own videos, and reads the rest of each video's basic details and status settings (the API's snippet and status) so that an update keeps them as they are. It reads which caption tracks each video has and whether the channel's playlist holds it. It does not upload videos, and it does not read or write comments or ratings.

The tool does not read the channel's statistics. It does not collect viewers' comments, names or any other information about viewers.

2. How it is used

Only to keep each video's title, description and disclosure as the channel's records give them, and to check those, its captions and its playlist against the records. Nothing is used for advertising or sold.

3. Where it is kept, and who else handles it

  • The tool runs on a computer we control. Its Google sign-in token is stored there, where only the tool's account can read it, and in that computer's weekly backup, which is encrypted before it leaves the computer. The tool does not store what it receives from YouTube: it compares it with the channel's records in the run that read it, and then discards it.
  • The publishing records (what each video's title, description and playlist should be) are the channel's own, written by the channel, not taken from the API. They are kept on that computer, in a private GitHub repository, and in the same weekly backup. The description each video should carry is also published, on purpose, in that episode's public GitHub repository.
  • The tool is run on that computer, under the same account, by two AI assistants: Claude Code, and Alpha (OpenClaw), the assistant that runs the channel. Claude Code uses Anthropic's Claude models, and so do Alpha's main models. They are told which of the tool's checks passed or failed, in terms of the channel's own records, the names of the details the tool changed and, when a call fails, its HTTP status; never the data YouTube sent back.
  • The assistants' own conversations go to the AI model providers they use. Claude Code's go to Anthropic, which keeps them for up to 30 days (up to 2 years if one is flagged as breaking its usage policy, longer to resolve a dispute or where the law requires it, and 5 years for anything sent to it as feedback). Alpha's main models are reached through OpenRouter on Google Cloud (Vertex AI) and Amazon Bedrock, on routes that keep none of them; any other model it uses is reached through OpenRouter on routes that keep no data.
  • Anthropic says it trains on conversations from accounts like ours only when their "Help improve Claude" setting is on; ours is off. Anything sent to it as feedback it may still use. OpenRouter lists Google Vertex and Amazon Bedrock as providers that do not train on prompts, and Google Cloud says it does not use data sent to the models it serves on Vertex AI to train or fine-tune any model without the customer's permission or instruction.

One more party sees what the assistants do: the computer's supervisor, a program that records what they do, whose own model calls also go through OpenRouter on routes that keep no data, and which sends its alerts only to us, by Telegram. None of these, and no one else, receives what the tool reads from YouTube, except where the law requires.

4. Cookies and advertising

The tool has no web interface. It places no cookies on anyone's device and shows no advertisements. This page is hosted by GitHub Pages, which logs each visitor's IP address for security purposes, and GitHub's own privacy statement covers visits to it.

5. How long it is kept, and how to remove it

  • The tool does not store data it receives through the YouTube API Services: it uses it in the run that reads it and then discards it, as YouTube's Developer Policies allow. So nothing stays behind to expire or to delete when a video is removed or access is revoked.
  • Access can be revoked at any time on Google's security settings page, security.google.com/settings/security/permissions. The tool can then no longer reach the account. The tool holds data about no one but the channel itself.
  • Questions or complaints: purdy1agent1alpha@gmail.com.
  • The tool deletes nothing on YouTube. To remove a video or its details from YouTube, use YouTube Studio.

6. Changes

If the tool ever reads or changes anything new, or is offered to anyone else, this policy changes first and the date above is updated.
