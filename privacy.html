Work Shown publisher Privacy Policy

Effective 24 November 2026. Earlier versions were effective 20, 22 and 23 November 2026.

Work Shown publisher ("the tool") is the program that the YouTube channel Work Shown ("we") uses to upload and update its own videos, to check each video's title, description, disclosure, captions and playlist against the channel's records, and to read the channel's own statistics for a short report on each episode. It uses the YouTube API Services.

It is not offered to anyone else: it runs only on our computer, and only Work Shown's own account is given a way to sign in to it, on our own devices. Google has not verified the app, which limits it to 100 accounts. By using the tool, its user, the channel, agrees to be bound by the YouTube Terms of Service. What Google does with data is set out in the Google Privacy Policy.

1. What the tool accesses

Only what the channel's account grants on Google's consent screen, two permissions:

  • "See, edit, and permanently delete your YouTube videos, ratings, comments and captions" (youtube.force-ssl), to publish the channel's videos;
  • "View YouTube Analytics reports for your YouTube content" (yt-analytics.readonly), to read the channel's statistics.

With the first, the tool uploads the channel's own videos, each as Private, sets their thumbnails, uploads their caption files and adds them to the channel's playlist. It sets each video's title, description, category, language and tags as the channel's records give them, and the same settings on every video: the altered or synthetic content disclosure, not made for kids, no paid product placement, the standard YouTube license, and embedding allowed. Once the tool's checks of a video pass and the channel has approved it, it changes the video from Private to Public.

It reads the rest of each video's basic details and status settings (the API's snippet and status) so that an update keeps them as they are, and it reads which caption tracks each video has, whether the channel's playlist holds it, and whether it is public. It does not read or write comments or ratings, and it deletes nothing.

With the second it reads YouTube's statistics for each of the channel's own videos:

  • views, watch time and average view duration;
  • how much of the video was watched at each point (audience retention);
  • what kind of source the views came from (YouTube search, suggested videos, outside links and so on);
  • day by day, how often its thumbnail was shown (impressions) and then clicked (click-through rate). These come from the YouTube Reporting API, so the tool also asks YouTube, once, to prepare that report each day.

These are counts, averages and rates across all viewers. The tool does not ask for them by country, age, gender or device, and it collects nothing about any one viewer: no comments, names or other details.

2. How it is used

Only to publish the channel's own episodes as the channel's records give them: to upload each one with its title, description, settings, thumbnail, captions and playlist, to keep those as the records give them, to check them against the records, and to make the video public once those checks pass and the channel has approved it.

And to report the statistics a week after each episode is released, so that the next episode's titles and thumbnails are chosen from what worked: to the channel, on a private page on our computer, and to a Claude model that helps make that choice (section 3). The report shows YouTube's numbers as YouTube gives them, with the dates they cover; the tool works out no scores of its own from them. Nothing is used for advertising or sold.

3. Where it is kept, and who else handles it

  • The tool runs on a computer we control. Its Google sign-in token is stored there, where only the tool's account can read it, and in that computer's weekly backup, which is encrypted before it leaves the computer. Apart from the statistics, the tool does not store what it receives from YouTube: it compares it with the channel's records in the run that read it, and then discards it.
  • The statistics are the one thing it keeps. They are stored on that computer, in a folder only the tool's account can read (the account the assistants run under; the tool never shows them its contents), which is left out of the weekly backup and out of every repository. The channel's report page is made from that folder.
  • The publishing records (what each video's title, description, thumbnail, captions and playlist should be) are the channel's own, written by the channel, not taken from the API. That includes each video's id, which the channel copies from YouTube Studio after an upload; the tool does not keep the id the API returns. They are kept on that computer, in a private GitHub repository, and in the same weekly backup. The description each video should carry is also published, on purpose, in that episode's public GitHub repository.
  • The tool is run on that computer, under the same account, by two AI assistants: Claude Code, and Alpha (OpenClaw), the assistant that runs the channel. Claude Code uses Anthropic's Claude models, and so do Alpha's main models. They are told which of the tool's checks passed or failed, in terms of the channel's own records, the names of the details the tool changed and, when a call fails, its HTTP status, and how many daily reach reports it read and for how many videos it kept or deleted statistics; never the data YouTube sent back.
  • The statistics are not shown to them either. The tool gives the report to a Claude model in a separate Claude Code session that keeps no log on the computer, and passes back only what that session chose for the next episode, without the numbers.
  • The assistants' own conversations go to the AI model providers they use. Claude Code's go to Anthropic, which keeps them for up to 30 days (up to 2 years if one is flagged as breaking its usage policy, as long as the law requires or a dispute needs, and 5 years for conversations sent to it with its feedback, bug-report and share commands). Alpha's main models are reached through OpenRouter on Google Cloud (Vertex AI) and Amazon Bedrock, on routes that keep none of them; any other model it uses is reached through OpenRouter on routes that keep no data.
  • Anthropic says it trains on conversations from accounts like ours only when their "Help improve Claude" setting is on; ours is off. Anything sent to it as feedback it may still use. OpenRouter lists Google Vertex and Amazon Bedrock as providers that do not train on prompts, and Google Cloud says it does not use data sent to the models it serves on Vertex AI to train or fine-tune any model without the customer's permission or instruction.

One more party sees what the assistants do: the computer's supervisor, a program that records what they do. Its own model calls also go through OpenRouter on routes that keep no data, and it sends its alerts only to us, by Telegram. Apart from the statistics that reach Anthropic as above, the tool gives what it reads from YouTube to none of these and to no one else, except where the law requires; it hands the statistics to that separate session as its input, never in a command.

4. Cookies and advertising

The tool has no web interface. It places no cookies on anyone's device and shows no advertisements. This page is hosted by GitHub Pages, which logs each visitor's IP address for security purposes, and GitHub's own privacy statement covers visits to it.

5. How long it is kept, and how to remove it

  • Apart from the statistics, the tool does not store data it receives through the YouTube API Services: it uses it in the run that reads it and then discards it.
  • The statistics are kept for as long as the channel uses them to compare its episodes. As YouTube's Developer Policies require, the tool checks that the channel's permission still stands and that each video still exists: each day the computer is on, and when it starts. If the permission has been revoked, it deletes all of them; if a video has been deleted, that video's.
  • Access can be revoked at any time on Google's security settings page, security.google.com/settings/security/permissions. The tool can then no longer reach the account, and its next check deletes the statistics. The tool holds data about no one but the channel itself.
  • The channel can have the statistics deleted at any time with the tool's delete command, which deletes them at once and stops the tool collecting them until the channel turns it back on. Deleting them here changes nothing on YouTube.
  • For questions or complaints, write to purdy1agent1alpha@gmail.com.
  • The tool keeps no other copy of them on the computer: the assistants that run the tool never see them, and the session that reads the report is started so that it keeps no log. Anthropic deletes what it received as section 3 says.
  • The tool deletes nothing on YouTube. To remove a video or its details from YouTube, use YouTube Studio.

6. Changes

If the tool ever reads or changes anything new, or is offered to anyone else, this policy changes first and the date above is updated.
